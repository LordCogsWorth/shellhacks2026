Walking paths

This prototype proposes walking routes for review by a sighted operator. It is not validated as a mobility aid. Route requests never start the motors. Camera detections cannot establish whether a crossing is safe, read pedestrian signals reliably, or locate objects precisely.

What is shared

A chat request sends your message and preset destination names to OpenAI. The Pi sends the current phone coordinates and the selected destination coordinates to Google Routes. Loading the Google map shares map requests with Google. Camera frames travel from the phone to the Pi and dashboard; this feature does not send them to OpenAI. Object detection runs in the dashboard browser.

Route geometry and hazard observations are held in Pi memory until restart. Preset destinations and API configuration remain on the Pi. The service is intended for your trusted hotspot and has no user authentication.

Setup

Configure private provider keys in /home/pi/guide-dog-live/pi/navigation.env. Save preset names, aliases and verified coordinates in /home/pi/guide-dog-live/pi/destinations.json. See NAVIGATION_SETUP.md in the project for the exact format. Keep secret keys out of browser files and chat.

Map terms

Google Maps features are subject to the Google Maps terms and Google privacy policy. OpenAI requests are governed by your API account agreement and OpenAI privacy policy. Public distribution requires operator-specific terms and a publicly accessible privacy policy.

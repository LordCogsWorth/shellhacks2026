Connect iPhone GPS

Keep the Pi connected to this iPhone’s hotspot. Follow these steps in Safari.

  1. Download the robot’s certificate. Allow the profile download.
  2. Open Settings → General → VPN & Device Management. Install Guide Dog Robot Local CA.
  3. Open Settings → General → About → Certificate Trust Settings. Enable full trust for Guide Dog Robot Local CA. This trusts certificates issued by this robot’s private certificate authority; only do this for your own robot.
  4. Open the secure GPS page. Tap Start GPS and allow location access. Keep the page open.
